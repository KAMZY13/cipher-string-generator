# Cipher

Cipher is a random string generator built with React and Tailwind CSS.

## Features

- Generate random strings instantly
- Adjustable string length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Copy to clipboard

## Technologies Used

- React
- Tailwind CSS
- JavaScript
- Vite

## Installation

```bash
npm install
npm run dev
```
